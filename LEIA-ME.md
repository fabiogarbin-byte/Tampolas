# 🍺 Tampolas — Guia de Publicação no GitHub Pages

## Arquivos do projeto
```
tampolas-app/
├── index.html
├── style.css
├── app.js
├── manifest.json
└── icon.svg
```

## Passo a passo para publicar

### 1. Criar conta no GitHub
Acesse https://github.com e crie uma conta gratuita (se ainda não tiver).

### 2. Criar repositório
- Clique em **"New repository"** (botão verde)
- Nome: `tampolas`
- Deixe como **Public**
- Clique em **"Create repository"**

### 3. Subir os arquivos
Na tela do repositório vazio, clique em **"uploading an existing file"**:
- Arraste os 5 arquivos: `index.html`, `style.css`, `app.js`, `manifest.json`, `icon.svg`
- Clique em **"Commit changes"**

### 4. Ativar GitHub Pages
- Vá em **Settings** (engrenagem) → **Pages** (menu lateral)
- Em "Branch", selecione **main** e clique em **Save**
- Aguarde ~1 minuto

### 5. Acessar o app
Seu app estará em:
```
https://SEU_USUARIO.github.io/tampolas/
```

---

## Para atualizar o app no futuro
1. Faça as alterações nos arquivos localmente
2. No GitHub, abra o arquivo que mudou
3. Clique no ícone de lápis (✏️ Edit)
4. Cole o novo conteúdo
5. Clique em **"Commit changes"**

O site atualiza em segundos automaticamente.

## Instalar no celular como app
### iPhone (Safari):
1. Abra o link no Safari
2. Toque em compartilhar (⬆️)
3. "Adicionar à Tela de Início"

### Android (Chrome):
1. Abra o link no Chrome
2. Menu (⋮) → "Adicionar à tela inicial"
